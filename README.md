# Lab-Exercise-3

Aim:

To design a simple and user-friendly e-commerce mobile application interface using Canva that allows users to search for products, browse different categories, view offers, and purchase items easily.

Algorithm:
~~~
Open Canva and create a mobile screen design.
Add the app name and logo.
Design the location and address section.
Create a search bar with voice and camera search options.
Add product categories such as Fashion, Mobiles, Electronics, Beauty, and Home.
Include promotional offers and discount coupons.
Display recommended products with images and names.
Add a bottom navigation bar (Home, Play, Profile, Cart).
Arrange all elements neatly and apply suitable colors and icons.
Save and export the final app interface.
~~~
